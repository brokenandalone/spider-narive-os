# Webbie face v1

`webbie-face-v1.png` is the new portrait used by The Web's native Webbie tab.
The existing Webbie wallpapers remain intact.

Created with built-in image generation. Prompt: an ethereal adult woman's face
made of luminous violet light and soft lavender mist, centered front-facing
head and shoulders, cinematic 3D holographic wisps and flowing hair, welcoming
expression, dark plum background; no text, logos, watermark or red.

The panel pulses the portrait halo while a typed reply is pending or the installed
agent's `webbie-speaking` marker is present. It does not claim microphone activity,
voice identity, or lip synchronization. Missing portraits fall back to text.

`webbie-face-speaking-v1.png` is an edit generated with the same built-in tool:
change only the lips to a natural slightly open speaking mouth, keeping the
identity, framing, eyes, hair, lighting and background unchanged. The UI blends
only a mouth-region overlay, keeping the rest of the portrait stationary.
The speaking marker gates lip movement; silence/thinking restores closed lips.
This is an approximate speech animation. Phoneme/audio synchronization is pending.
